# 🎬 Movie App

A simple movie browsing application built with **Vanilla JavaScript** that fetches movie data from the **TMDB API** and displays popular movies with ratings, posters, and descriptions.

## 🚀 Features

* Displays popular movies from TMDB
* Search movies by title
* Shows movie poster, rating, and overview
* Color-coded ratings (good, average, bad)
* Responsive and simple UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Fetch API
* TMDB (The Movie Database) API

## 📦 API Used

**TMDB API** – for fetching movie data and search results

https://www.themoviedb.org/

## ⚙️ How It Works

1. The app fetches popular movies using the TMDB API.
2. Movie data such as title, rating, poster, and overview is retrieved.
3. The movies are dynamically displayed on the page using JavaScript.
4. Users can search for movies using the search input.

## 🔧 Setup

1. Clone the repository

```
git clone https://github.com/YOUR_USERNAME/javascript-movie-app.git
```

2. Open the project folder

3. Run the project by opening `index.html` in your browser.
